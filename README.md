# WPV-API
This repository links below to the Workplace Violence Prediction API, where I worked as a developer in an Agile team of 6.

### [Workplace Violence Prediction API](https://github.com/averybobbitt/workplace-violence-prediction-api)

A team-based project focused on predicting workplace violence risk using simulated hospital-system data.  
This project involved:
* Creating a detailed MySQL database to hold both our ML model training data, as well as our simulated risk level data
* Creating a Django REST backend service to simulate periodic polling of hospital systems for data
* Creating a dashboard to visualize the most recent WPV prediction level

**My contributions included:**

* Designed and created the MySQL database
* Created database schema documentation and deliverables
* Built the background task process for polling simulated hospital systems
* Designed the original UI layout
* Implemented the visual representation of prediction values
* Completed the System Implementation Manual, the project's final deliverable
